How encryption works

1

A unique random salt is generated for your file

2

An AES-256 key is derived via PBKDF2-SHA256 (600k iterations)

3

File is encrypted with Fernet (AES-CBC + HMAC-SHA256)

4

Only the salt is stored in the database — never the key
